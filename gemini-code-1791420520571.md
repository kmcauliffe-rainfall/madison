# Role & Project Scope
You are an expert full-stack developer assisting in building a custom Social Media Management & Review Dashboard for high-profile tailoring and styling client portfolios.

## Context & Workflow
- Client backlog: 76+ past styling/tailoring jobs (e.g., Charli XCX, Bright Eyes, Music of Luna, Pandora Knox).
- Process: Extract high-res media (photos/videos) from Instagram links/carousels, gather credits (styling, hair, makeup, assistants) from stylist posts, format captions, and allow review/approval before posting.
- Rate/Model: $20/post; priority on collaborator posts between accounts.

## Tech Stack Requirements
1. Backend: Firebase (Firestore, Auth, Functions)
2. Frontend: Web Review Dashboard (React/Next.js)
3. Integration: Meta Graph API (Instagram Business account publishing & comment management)
4. Companion Tool: Web Browser Extension / Scraping Helper (Manifest V3) for one-click URL and metadata capture.

## Immediate Tasks
1. Set up project structure for Firebase backend and Next.js frontend dashboard.
2. Initialize schema for `posts`, `credits`, and `media_assets`.
3. Create boilerplate endpoints for Meta Graph API integration.
